# Cadastro da Rifa - Moto Yamaha MT-07 0km

Este projeto é um site simples para cadastro de participantes em uma rifa de uma moto Yamaha MT-07 0km.

## Funcionalidades

- Formulário de cadastro com campos para nome, e-mail e telefone (WhatsApp).
- Aceite obrigatório dos termos e condições.
- Feedback visual com toast de confirmação após o cadastro.
- Layout responsivo utilizando Bootstrap 5.
- Imagem ilustrativa da moto e destaque para o valor da rifa.

## Como usar

1. Abra o arquivo `index.html` em seu navegador.
2. Preencha o formulário com seus dados.
3. Aceite os termos e clique em "Participar do Sorteio".
4. Você verá uma mensagem de confirmação e deverá verificar seu e-mail para receber o número da rifa.

## Estrutura do Projeto

- `index.html`: Página principal com o formulário de cadastro.
- `images/MT-07.png`: Imagem da moto Yamaha MT-07.
- `readme.md`: Este arquivo de documentação.

## Tecnologias Utilizadas

- HTML5
- CSS3 (via Bootstrap 5)
- JavaScript (para validação e feedback)

## Observações

- Este projeto é apenas um exemplo didático e não realiza cadastro real ou envio de e-mails.
- Para personalizar, altere os textos e imagens conforme necessário.
